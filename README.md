# Maison Élise — Luxury Site Preview

Этот проект — статический сайт. Чтобы избежать ошибки **Not Found**, нужно запустить локальный сервер в корне репозитория.

## Быстрый запуск

```bash
./preview.sh
```

После запуска откройте в браузере:

```
http://127.0.0.1:8000/index.html
```

## Альтернатива (ручной запуск)

```bash
python -m http.server 8000
```

Далее откройте:

```
http://127.0.0.1:8000/index.html
```

> Если попытаться открыть `index.html` напрямую через `file://`, браузер может блокировать стили и скрипты. Лучше использовать локальный сервер.
